# korean-spell-check

원본: https://github.com/NomaDamas/k-skill/tree/main/korean-spell-check

한국어 맞춤법 검사 스킬만 분리한 6파일 저장소입니다. 저장소 루트의 SKILL.md로 가져올 수 있습니다. 원본 Python helper와 skill.json은 그대로 보존했고 안내의 실행 예시만 로컬 Python 경로로 바꿨습니다. 원본 MIT LICENSE를 포함합니다.

Python 3.10+와 인터넷 연결이 필요하며 별도 pip 의존성은 없습니다. 외부 서비스 이용 가능 여부와 정책은 별개입니다. 민감정보를 보내지 말고 비상업적 개인·학생 저빈도 검수에 사용하세요.
